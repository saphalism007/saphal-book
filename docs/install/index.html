Install it

On a computer it runs as an app. On a phone or tablet it runs in the browser and sits on the home screen like one.

iPad, iPhone or Android

Nothing to download

It runs in the browser and adds itself to the home screen.

Open Saphal Book then add it to your home screen
  1. iPad or iPhone: open in Safari, tap Share, then Add to Home Screen. Chrome on an iPad cannot do this part, it has to be Safari.
  2. Android: open in Chrome, tap the three dots, then Install app.

Mac

Download and open

Download for MacmacOS 12 or newer
  1. Open the downloaded file. Drag Saphal Book to Applications.
  2. The first time, right click the icon and choose Open, then Open again. macOS asks this once for anything not from the App Store.
  3. It opens in your browser at your own machine. Keep it in the Dock.

Windows

Download and open

Download for WindowsWindows 10 or newer
  1. Unzip it somewhere you will keep it, such as Documents.
  2. Double click Saphal Book.
  3. If Windows shows a blue box, click More info then Run anyway. It asks this once.
Windows needs Python. If it will not start, install it from python.org and tick Add Python to PATH during setup, then open Saphal Book again. A Mac already has what it needs.

Using more than one device

Sign in with the same name everywhere and your books follow you. What is entered on one device reaches the others by itself.

Books kept in a browser belong to that browser on that device, so pick one place to keep the real ones and sign in there.
